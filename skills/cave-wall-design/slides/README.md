# Sample slides

Three reusable 1280×720 slide templates for the Cave Wall system:

- `title-slide.html` — hero painted title + subtitle, red-ochre hand prints as flanking decoration.
- `quote-slide.html` — big painted pull-quote with an attribution scrawl.
- `grid-slide.html` — 4-up parchment panels. Good for feature / step / concept lists.

All share the same wall background treatment and the shared pictograph defs inline. Scale the slide by wrapping in `<deck-stage width="1280" height="720">` or by replacing the root `<section>`.
