# Cave Wall UI kit

A hand-painted "information surface" for a Paleolithic tribe: notices, hunt tallies, and a wall-mounted map. Two fictional product surfaces:

1. **Tribe Notice Wall** — the home screen. Painted announcements and the day's tally.
2. **Hunt Log** — an inbox-like list of past hunts with status chips.

Open `index.html` to see them composed together.

Components:
- `Wall.jsx` — full-bleed cave wall surface with friezes
- `Notice.jsx` — a painted announcement card
- `HuntRow.jsx` — a log entry with pictograph and status chip
- `Chip.jsx`, `Button.jsx`, `Frieze.jsx`, `Pictograph.jsx` — primitives
